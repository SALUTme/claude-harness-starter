# claude-harness-starter

Готовый харнес для Claude Code и Codex: упряжь вокруг ИИ, которая ведёт проект от идеи до результата. Внутри структура проекта, скилы, самопроверка и память о каждом решении.

Промпт решает задачу. Харнес ведёт проект.

## Как установить

Нужен Mac или Windows 10/11 (Windows — бета, см. [WINDOWS_TEST.md](WINDOWS_TEST.md)) и ИИ-агент: Claude Code (приложение Claude с вкладкой Code или терминал) или Codex (бета). Аккаунт на GitHub не нужен.

Напиши агенту:

> Действуй по инструкции https://raw.githubusercontent.com/SALUTme/claude-harness-starter/main/SETUP.md — настрой мой харнес.

Агент сам проверит компьютер, создаст папку проекта, поставит скилы и плагин, проверит защиту и скажет, как перезапуститься. Перед каждой установкой он спросит разрешение.

## Что дальше

Открой Claude Code или Codex в папке проекта и напиши «привет». Правила, скилы и вики у них общие: проект можно открывать в обоих. Навигатор скажет, на каком этапе проект, и предложит следующий шаг. Подготовка начинается с интервью: ИИ задаёт вопросы, ты отвечаешь. Команды запоминать не нужно.

Харнес настроен для исследований: собираем данные, ведём вики, делаем таблицы, схемы и отчёты. Проверкой служит вики: у каждого факта есть источник, ссылки живые, журнал ведётся, страницы связаны.

## Что внутри

| Путь | Что это |
|---|---|
| `.claude/skills/harness` | Навигатор: определяет этап и предлагает следующий шаг |
| `.claude/skills/harness-setup` | Подготовка проекта по фазам: интервью, цель, план, скилы, вики, защита, проверка |
| `.claude/skills/unlazy` | Условия готовности: работа не считается сделанной, пока каждое условие не проверено |
| `.claude/skills/find-skills` | Поиск и установка новых скилов из каталога skills.sh |
| `.claude/skills/skill-creator` | Создание своих скилов |
| `.claude/skills/deep-research` | Глубокое исследование: каждый вывод подтверждён тремя независимыми источниками |
| `.claude/skills/user-research` | План интервью и опросов |
| `.claude/skills/research-synthesis` | Выводы из интервью, отзывов и данных |
| `.claude/hooks/` | Защита от опасных команд и утечки секретов, проверки, статус проекта при старте |
| `.claude/settings.json` | Права, хуки, плагин oh-my-claudecode |
| `.claude/harness.env` | Команды проверок, заполняются при подготовке |
| `.harness/` | Прогресс подготовки и адрес основы |
| `AGENTS.md` | Правила проекта для любого агента; заменяется при подготовке проекта |
| `CLAUDE.md` | Импорт `@AGENTS.md` для Claude Code |
| `.codex/hooks.json` | Те же хуки защиты для Codex, через переходник `codex-adapter.sh` |
| `.agents/skills` | Создаётся при установке: скилы для Codex |
| `SETUP.md` | Инструкция установки для Claude |

Плагин [oh-my-claudecode](https://github.com/Yeachan-Heo/oh-my-claudecode) v5.6.1 ставится при установке. Он даёт глубокое интервью, параллельных исследователей и независимых агентов проверки.
