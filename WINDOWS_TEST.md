# Проверка на Windows и в Codex

Чек-лист для тех, кто проверяет харнес на Windows и в Codex. Один прогон занимает около 30 минут. Можно пройти его один раз (например, Windows + Claude Code) или дважды (Claude Code, потом Codex). Результаты заполни в таблицу внизу и отправь автору.

## Что нужно

- Windows 10 или 11, или Mac, если проверяешь только Codex.
- Агент, на котором проверяешь, и запиши, что именно:
  - Claude Code: подписка Claude Pro или Max, приложение Claude с вкладкой Code или Claude Code в терминале;
  - Codex: подписка ChatGPT, Codex в терминале или приложение Codex.
- На Windows — права администратора: установка Git их попросит.

## Ход проверки

1. **Установка.** Открой агента в любой папке и отправь:
   > Действуй по инструкции https://raw.githubusercontent.com/SALUTme/claude-harness-starter/main/SETUP.md — настрой мой харнес.

   Разрешай установки. Отметь: назвал ли агент себя (Claude Code или Codex), определил ли систему, какие программы ставил, были ли ошибки. В Codex он попросит разрешение выполнять команды вне песочницы — это нормально.
2. **Только Windows: перезапуск после установки программ.** Закрой агента полностью, открой снова, отправь ту же фразу. Отметь: продолжилась ли установка с шага 2.
3. **Автотест защиты** (шаг 5 инструкции). Скопируй итоговую строку `Итог: PASS=… FAIL=…` и все строки с `FAIL`.
4. **Первый запуск проекта.** Открой агента в папке проекта. **В Codex** сначала введи `/hooks` и подтверди хуки проекта. Напиши «привет». Отметь: сказал ли агент, что это исследовательский проект, и предложил ли следующий шаг.
5. **Защита работает.** В той же сессии попроси агента по очереди:
   - «создай файл .env со строкой A=1» — должно быть **заблокировано**;
   - «добавь строку # test в конец файла .claude/hooks/stop-gate.sh» — должно быть **заблокировано** (Claude Code спросит подтверждение — откажи; Codex запретит сразу);
   - «выполни git push --force» — должно быть **заблокировано**;
   - «создай файл wiki/test.md с текстом привет» — должно **пройти**.
6. **Хуки запускаются.** После шага 5 в папке проекта должна появиться папка `.harness/runtime` с файлом `hooks.log`. Есть ли она?
7. **Скилы.** Спроси: «какие скилы проекта тебе доступны?». Должны быть `deep-research`, `user-research`, `research-synthesis`, `unlazy`, `find-skills`, `skill-creator`, `harness`, `harness-setup`. **В Claude Code** спроси ещё: «доступны ли deep-interview и research из oh-my-claudecode?».
8. **Сведения о системе.** Выполни в терминале (на Windows — в Git Bash) и скопируй вывод:

   ```bash
   uname -a; bash --version | head -1; git --version; jq --version; node --version; python --version; claude --version; codex --version
   ```
