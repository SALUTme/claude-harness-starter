# Проверка на Windows

Чек-лист для тех, кто проверяет харнес на Windows. Займёт около 30 минут. Результаты заполни в таблицу внизу и отправь автору.

## Что нужно

- Windows 10 или 11.
- Подписка Claude (Pro или Max) и Claude Code: приложение Claude с вкладкой Code или Claude Code в терминале. Запиши, что именно.
- Права администратора на компьютере: установка Git их попросит.

## Ход проверки

1. **Установка.** Открой Claude Code в любой папке и отправь:
   > Действуй по инструкции https://raw.githubusercontent.com/SALUTme/claude-harness-starter/main/SETUP.md — настрой мой харнес.

   Разрешай установки. Отметь: определил ли Claude систему как Windows, какие программы ставил, были ли ошибки.
2. **Перезапуск после установки программ.** Закрой Claude Code полностью, открой снова, отправь ту же фразу. Отметь: продолжилась ли установка с шага 2.
3. **Автотест защиты** (шаг 5 инструкции). Скопируй итоговую строку `Итог: PASS=… FAIL=…` и все строки с `FAIL`.
4. **Первый запуск проекта.** Открой Claude Code в папке проекта, напиши «привет». Отметь: сказал ли Claude, что это исследовательский проект, и предложил ли следующий шаг.
5. **Защита работает.** В той же сессии попроси Claude по очереди:
   - «создай файл .env со строкой A=1» — должно быть **заблокировано**;
   - «выполни git push --force» — должно быть **заблокировано**;
   - «создай файл wiki/test.md с текстом привет» — должно **пройти**.
6. **Хуки запускаются.** После шага 5 в папке проекта должна появиться папка `.harness/runtime`. Есть ли она?
7. **Плагин.** Спроси: «какие скилы oh-my-claudecode тебе доступны?». Есть ли в ответе `deep-interview` и `research`?
8. **Сведения о системе.** В Git Bash выполни и скопируй вывод:

   ```bash
   uname -a; bash --version | head -1; git --version; jq --version; node --version; python --version; claude --version
   ```
